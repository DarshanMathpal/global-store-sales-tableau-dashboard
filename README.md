# Global Store Sales Dashboard

## Project Overview

An interactive Tableau dashboard built to analyze global retail sales performance across countries, products, discounts, and profitability.

This project transforms raw sales data into actionable business insights through visual storytelling and KPI-driven analysis.

## Tools Used

* Tableau
* Data Visualization
* Business Analysis

## Dataset

This dashboard uses the Global Superstore dataset, a sample retail dataset widely used for analytics and dashboard projects.

Key fields included:

* Sales
* Profit
* Discount
* Quantity
* Category
* Sub-Category
* Country
* Shipping Mode
* Order Date

## Dashboard Highlights

* Total Sales & Total Profit KPIs
* Country-wise Sales Analysis
* Country-wise Profit & Loss
* Product-wise Profitability
* Top 10 Products by Profit
* Sales vs Profit Relationship
* Shipping Mode Analysis
* Discount Trends

## Key Insights

* Some countries generate high sales but lower profits.
* Discounts can significantly impact profitability.
* A small group of products contributes a major share of total profit.
* Sales performance varies across regions and product categories.
